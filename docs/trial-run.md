# 試験運用の確認表（段階 7）

実際の予約で使い始める前に、テスト予約で一通りの流れを確かめ、その後に数件の実際の予約で運用する。
気づいたこと（不具合、分かりにくい表示、手間のかかる操作）は、最後の「気づいたことの記録」に書く。

- 確認した項目は `[ ]` を `[x]` にし、担当者の名前と日付を書く
- テスト予約は、カレンダーで区別して表示され、7 日後に自動で削除される。通知メールの件名には「[テスト]」が付く

## 0. 始める前に

- [ ] Cloudflare のダッシュボードで、最新のデプロイが成功している（Worker の「デプロイ」で、最新のコミットが一番上にある）
- [ ] 管理画面（`https://checkinmanagement.tamahouse0930.workers.dev/admin`）に、管理者 3 名がそれぞれログインできる
- [ ] 「初期設定」→「Google ドライブ・Gmail との連携」が連携済みになっている
- [ ] 「初期設定」の通知メールの宛先に 3 名が登録され、「テストメールを送る」で全員に届く
- [ ] 「初期設定」→「予約の取り込み（iCal）」に Airbnb・Booking.com の URL が登録され、カレンダーの「最新化」で実際の予約が表示される
- [ ] 「初期設定」→「基本情報」の事業者名・問い合わせ先、チェックイン／チェックアウト時刻が正しい
- [ ] 「設定」→「文面」の案内文（日本語・英語・韓国語・中国語 2 種）に誤りがない
- [ ] 「初期設定」→「チェックイン用タブレットの登録」で、玄関のタブレットを登録した

## 1. テスト予約で流れを確かめる

カレンダーの日付を押し、「テスト予約にする」で、**今日がチェックイン日**のテスト予約を作る（タブレットで確かめるため）。
ゲスト役は、できれば **iPhone（Safari）と Android（Chrome）の両方**で行う。

### 1-1. URL を送る（管理者）

- [ ] 予約の画面「① 宿泊者入力画面の URL を送る」で案内文をコピーすると、「送信済み」の印が付く
- [ ] コピーした案内文を自分のスマホに送り、URL を開ける

### 1-2. 宿泊者の入力（ゲスト役のスマホ）

3 人（代表者は日本人、同行者 1 人は外国籍、もう 1 人は同行者用リンクで本人が入力）で試す。

- [ ] 画面の言語を切り替えられる（日本語・英語・韓国語・中国語 2 種）
- [ ] 人数を 3 人にできる
- [ ] 代表者（日本人）: 身分証をスマホのカメラで撮影でき、写真が表示される
- [ ] 外国籍の人: パスポートの顔写真のページを撮影すると、「パスポートを読み取っています…」の後に、空欄の旅券番号・国籍・氏名が入る
- [ ] 外国籍の人: 先に旅券番号を入力しておいた場合は、入力した番号がそのまま残る
- [ ] 外国籍の人: 旅券番号をわざと 1 文字変えても、ゲストの画面には何も表示されない
- [ ] 3 人目の枠の「リンクを共有」で同行者用の URL が出て、別のスマホで開くと自分の枠だけを入力できる
- [ ] 入力の途中でブラウザを閉じても、URL を開き直すと続きから入力できる
- [ ] 全員分がそろうと、同意にチェックして送信でき、「承認待ち」になる

### 1-3. 承認と暗証番号（管理者）

- [ ] 登録の通知メールが届く。旅券番号を変えた人の名前が「※ パスポート番号が…違う人がいます」として書かれている
- [ ] 「② 登録内容の確認」の先頭に赤い帯で不一致の人が表示され、その人のカードが赤枠で「パスポート番号 不一致」と表示される
- [ ] 身分証・パスポートの写真が表示され、押すと大きく開く
- [ ] 「承認」の確認に、不一致の人の名前が表示される
- [ ] 差し戻し（理由を入力）→ ゲストの画面に理由が表示され、修正して送り直せる
- [ ] 承認すると、ゲストの画面が「承認済み」になり、暗証番号は表示されない
- [ ] 「③ 暗証番号を送る」で暗証番号を保存し、案内文をコピーすると「送信済み」の印が付く
- [ ] Google ドライブの「TAMAHOUSE宿泊者写真 / _test」の下に、この予約のフォルダと写真がある（読み取り用の一時ファイル `_ocr_…` は残っていない）

### 1-4. チェックイン・チェックアウト（玄関のタブレット）

- [ ] 言語を選び、「チェックイン」を押すと、承認済みの 3 人の名前が「テスト」と添えて表示される
- [ ] 名前を押すとカメラが起動し、カウントダウンの後に撮影される。撮り直しもできる
- [ ] 1 人だけチェックインすると、「チェックインが始まりました」のメールが届く
- [ ] 残りの人もチェックインすると、「全員がチェックインしました」のメールが届く
- [ ] チェックアウトすると、「チェックアウトしました（清掃を始められます）」のメールが届く
- [ ] 60 秒操作しないと、最初の画面（言語の選択）に戻る
- [ ] ピンチでの拡大、長押しのメニュー、文字の選択ができない
- [ ] アクセスガイド（iPad）またはアプリ固定（Android）で、ほかのアプリに切り替えられない
- [ ] 「チェックアウト」→ 確認 → 「鍵を必ずキーボックスに返してください」が表示される

### 1-5. チェックイン後（管理者）

- [ ] 「④ チェックイン・写真の照合」で、身分証の写真と当日の写真が並ぶ
- [ ] 「全員を確認した：照合 OK」を押せる。「不一致あり」で内容を記録できる
- [ ] 「名簿管理」で期間と氏名で検索でき、宿泊の名簿に写真が並ぶ
- [ ] 名簿の印刷・PDF が、保健所に見せられる見た目になっている
- [ ] CSV を出力すると、テスト予約は含まれない

### 1-6. 後片付け

- [ ] テスト予約を削除すると、Google ドライブのフォルダも消える

## 2. 実際の予約で運用する

最初の数件（目安: 3 件、うち 1 件は外国籍のゲスト）は、次の点に特に気を付ける。

- [ ] 予約サイトのメッセージで URL を送った後、ゲストが迷わず入力できたか（問い合わせがあれば内容を記録する）
- [ ] 明日チェックインで未登録（URL送信済み・入力中）の予約が、「要対応」の「前日未登録」に数えられ、18 時に「明日チェックインの予約で、宿泊者の登録が済んでいません」のメールが届くか
- [ ] 当日、タブレットでのチェックインがゲストだけでできたか（駆けつけが必要になったら理由を記録する）
- [ ] パスポートの読み取りで、番号が正しく入ったか。読み取れなかった場合は、写真の状態（反射、ピンぼけ、傾き）を記録する
- [ ] チェックアウトが押されないまま時刻を過ぎた場合に、「チェックアウトが未操作です」のメールが届き、「要対応」の「チェックアウト未操作」に表示されるか
- [ ] 予約サイト側でキャンセルされた予約が、次の取り込みでカレンダーに取り消し線で表示され、「予約の取り込みで確認が必要なことがあります」のメールが届くか
